Enterprise AI System Architecture Overview

The Enterprise AI System is a scalable platform built with FastAPI, PostgreSQL, Redis, and LangGraph.

Core Technologies and Relationships:
- FastAPI serves as the primary REST API backend server.
- FastAPI connects to PostgreSQL for vector embeddings and document storage.
- PostgreSQL uses the pgvector extension to store 384-dimensional vector embeddings generated by HuggingFace MiniLM.
- FastAPI uses Redis for multi-turn chat memory caching and session locks.
- LangGraph orchestrates AI workflows including Tool Agent, RAG Node, and GraphRAG Service.
- React Frontend connects to FastAPI to provide interactive Chat, Knowledge Graph Canvas, and Evaluation Metrics dashboards.
- Docker Compose containerizes FastAPI, PostgreSQL, Redis, and React Nginx servers into an isolated network.
